## One-Paragraph Summary

SnehasClients is a Next.js 16 App Router web application for insurance customer administration. It provides secure admin login (NextAuth Credentials), customer CRUD operations (add/search/update/delete), MongoDB persistence via Mongoose, and defensive security headers for deployment. It is designed for a small operations workflow where authenticated admins manage policy-holder data with consistent field validation and controlled API access.
